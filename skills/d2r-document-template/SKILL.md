# D2R Document Template Skill

Use this skill to produce polished corporate documents that match the D2R AI Labs standard.

## Purpose

Create professional internal or client-facing documents with:
- Calibri-based typography
- title page formatting
- structured headings
- page numbers and footer details
- consistent corporate layout

## Output expectations

- Produce a complete document draft in Word-compatible .docx format or a structured markdown-first document if a .docx export is required.
- Maintain the D2R corporate style and consistent section hierarchy.
- Include placeholders for metadata such as document title, owner, date, and version.

## Workflow

1. Ask for the document type and purpose.
2. Gather product, client, or project context.
3. Draft the structure with title page, executive summary, body sections, and references.
4. Apply the D2R template styling consistently.
5. Provide a final polished document and suggest any missing facts.
